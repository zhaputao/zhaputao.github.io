机器人项目(1)——入门安装

发表于2026-06-08|更新于2026-08-16|机器人
|总字数:3.4k|阅读时长:12分钟|浏览量:

这篇文章记录的是我从 Mac 搭建 Ubuntu + ROS 2 学习环境的第一步。

由于电脑配置的原因，我的是Apple Silicon 芯片，我没有在 macOS 原生安装 ROS 2。而是采用的下面的配置步骤

这样做的好处是：ROS 2 的主流资料和软件包大多围绕 Ubuntu 展开，后面学习 Gazebo、RViz、TurtleBot3、Nav2 时会少绕很多弯。刚开始不用把所有工具一次性装完，先搭一个稳定的工作台，后面再一点点往上加东西，就已经很够用了。

安装 UTM 和 Ubuntu

下载 UTM

先去 UTM 官网 下载 UTM，直接点击 Download 即可。官网版和 App Store 版功能类似，但 App Store 版流程更麻烦，而且收费，所以这里更推荐官网版。

下载 Ubuntu 镜像

Apple Silicon 芯片需要选择 ARM64 / AArch64 版本的 Ubuntu。

如果只是学习 Linux 命令和 SSH，Ubuntu Server 会更轻；如果后面要跑 Gazebo、RViz、TurtleBot3 这类图形工具，更推荐 Ubuntu Desktop。

这里建议使用 Ubuntu 24.04 ARM64，因为 ROS 2 Jazzy 正好对应 Ubuntu 24.04：

  • Ubuntu 24.04 Noble ARM64 镜像
  • 如果只是做基础练习，也可以参考 Ubuntu 22.04 ARM64 镜像

我一开始装过 ubuntu-22.04.5-live-server-arm64.iso，后来为了 ROS 2 Jazzy 和 Gazebo 路线，改成了 Ubuntu 24.04 ARM64。这个小弯路也提醒我：机器人环境最好先确定 ROS 2 版本，再反推 Ubuntu 版本。

在 UTM 中创建新的 Ubuntu 虚拟机

打开 UTM，点击加号，新建一个虚拟机。

  1. 选择 Virtualize，不要选 Emulate。Apple Silicon 上虚拟化 ARM64 Ubuntu 会更快。
  2. 操作系统选择 Linux。
  3. 点击 Browse，选择刚刚下载的 Ubuntu ISO 文件。
  4. 内存、CPU 可以先按默认值，如果 Mac 内存比较充足，可以适当多给一点。
  5. 存储空间建议至少 30GB；如果后面要跑 Gazebo、TurtleBot3、Nav2，更建议 40GB 到 60GB。
  6. 共享文件夹可以选一个 Mac 本地目录，方便以后在 Mac 和虚拟机之间传文件。

最后检查配置，可以给虚拟机起一个容易识别的名字，比如 Ubuntu-Robot。注意看架构是否是 arm64 或 aarch64。

安装 Ubuntu 系统

选中创建好的虚拟机，点击播放键启动。

如果安装的是 Ubuntu Server，大致流程如下：

  1. 语言选择 English。
  2. 键盘布局保持默认，选择 Done。
  3. 安装版本选择 Ubuntu Server。
  4. 网络设置默认 DHCP 即可，看到 IP 地址后继续。
  5. 代理设置直接跳过。
  6. 镜像源地址会自动检测，如果显示 Fetched xxx KB in xs，说明网络可用。

磁盘分区选择 Use an entire disk。这里提示会清除磁盘数据，看起来有点吓人，但它清除的是虚拟机里面的虚拟磁盘，不是 Mac 本机硬盘。

接着设置用户名、密码和主机名。这里的 Username 后面会用于登录 Ubuntu，也会用于 SSH。

到 SSH Setup 时，建议按空格勾选：

这样后面可以直接从 Mac 终端连接 Ubuntu。Featured Server Snaps 可以都不选，直接继续。

安装完成后选择 Reboot Now。如果重启时黑屏，可以先在 UTM 右上角退出安装光盘，再重启虚拟机。只要最后能进入登录界面，并用刚才设置的用户名和密码登录，就说明安装成功了。

三星外接硬盘 + Ubuntu 桌面虚拟机

如果后面准备安装 ROS 2、Gazebo、TurtleBot3、Nav2，虚拟机会越来越大。Mac 本机磁盘不宽裕的话，可以把 Ubuntu 桌面虚拟机放到三星外接硬盘里。

这个选择很适合机器人学习，因为 Gazebo 仿真、地图文件、录屏、workspace 都会慢慢占空间。

外接 SSD

Ubuntu Server 比较轻，但跑 Gazebo 和 RViz 时，Ubuntu Desktop 更直观。桌面虚拟机的代价是体积更大，所以外接 SSD 会更舒服。

建议：

  • 只学 Linux / Python / ROS 2 基础：30GB 左右也能开始。
  • 要跑 Gazebo / TurtleBot3 / Nav2：建议 40GB 到 60GB 或更多。
  • 内存尽量给到 4GB 以上，如果 Mac 内存足够，可以给得更宽松一点。

迁移虚拟机的正确方式

如果虚拟机一开始装在 Mac 本机目录下，后面想迁移到外接硬盘，关键是：先关机，再移动整个虚拟机包。

推荐流程：

  1. 在 Ubuntu 中正常关机，不要只是挂起。
  2. 确认 UTM 里的虚拟机已经完全停止。
  3. 找到 .utm 虚拟机文件。
  4. 把整个 .utm 文件移动到三星外接硬盘。
  5. 从 UTM 中重新打开外接硬盘里的虚拟机。
  6. 启动 Ubuntu，检查能否正常进入系统。

不要在虚拟机运行时移动文件，也不要只移动里面某一个磁盘文件。虚拟机本质上是一整套文件，整体搬家最稳。
