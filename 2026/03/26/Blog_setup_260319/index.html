6️⃣ 将 Hexo 部署到 Github

这一部分可以参考大佬给出的，非常详细，图文并茂，我这里，只是简单列出，便于自己查找

  1. 打开 Github 账号，点击头像左边的加号，新建一个 repository
  2. 在 Repository name 这一栏，填入 Github_用户名+固定格式，比如我填写的是 zhaputao.github.io，其中 zhaputao 为Github_用户名，⚠️最后的固定格式.github.io 则必须保留。
  3. ☑️勾选下面的Add a README file,点击Create repository按钮，完成repository 的创建
  4. 退出hexo文件，添加 SSH Key 到 Github

比如我的是git config --global user.name "zhaputao"

比如我的是git config --global user.email "zhaputao@gmail.com"
也就是说， username 是你的 Github 用户名，example@example.com 是你 Github 的登录邮箱，引号需要保留。输入命令后直接回车就好，不会有其他提示。

  1. 通过终端命令生成 SSH Key

比如我的 ssh-keygen -t rsa -C "zhaputao@gmail.com"
输入代码后，按三下回车，然后可能会要求你输入密码，这个时候输入你的开机密码然后回车就好，执行完成后会在~/.ssh/id_rsa.pub目录下生成一个公钥文件id_rsa.pub。
(我的没要求输入密码)
文件不太好找，参考地址为：Macintosh HD/用户/zhaputao/.ssh/id_rsa.pub

  1. 右键 id_rsa.pub 这个文件，然后使用 文本编辑(电脑自带) 的方式打开，打开后复制里面的所有内容
  2. 打开，这个链接
  3. 点击右上角 New SSH Key，Title 可自定义，Key 的值就是上一步你复制的内容。复制好之后，点击Add SSH Key 按钮即可
  4. 打开终端，输入下面代码，测试是否成功
