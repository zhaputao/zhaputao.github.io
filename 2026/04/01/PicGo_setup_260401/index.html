vscode + github + PicGo配置,一个超级完美又舒适的markdown写作环境

发表于2026-04-01|更新于2026-04-13|博客相关
|总字数:1k|阅读时长:3分钟|浏览量:

原因是因为自己想写博客，而且自己一直偏爱vscode，在用其写md时，感觉高级无敌丝滑，但是部署到博客的时候，总是显示不出来图片，故又加上了PicGo。

如果大家只是使用vscode写md文件，感觉只用下几个我下面说的插件就ok了。

下面内容只在Mac环境下实践过，但其他环境应该都一样～

Vscode插件安装

  1. 打开vscode，点击左侧小方块，进行插件的安装

  2. 依次安装下面插件
    (1) Markdown All in One

  • 快捷键支持： 提供了丰富的快捷键，无需手动敲击符号即可完成排版，比如Ctrl+B 加粗，Ctrl+I 斜体等。

  • 列表自动补全： 当你写列表并敲击回车时，它会自动为你添加下一个列表编号或符号（比如 1. 后面自动接 2.或者自动续写 -），体验非常流畅。

  • 表格格式化： 可以一键将原本杂乱无章的 Markdown 表格代码对齐，变得整洁易读。
    (2) Markdown Preview enhanced

  • 支持渲染复杂图表： 可以在 Markdown 中直接编写代码并渲染出流程图、时序图、甘特图等。

  • 强大的导出功能： 可以将写好的 Markdown 文件一键完美导出为 PDF、HTML、PNG 或 JPEG，不用担心排版错乱。
    eg: 右键点击预览的文件，按照图片所示，生成pdf。

  • 精准双向同步： 编写文本时，右侧的预览窗口会非常精准地跟随你的光标位置实时滚动，反之亦然。(👍🏻方便的不行！！！！！)
    (3) Paste Image

  • 原生 Markdown 插入图片非常繁琐（需要手动保存图片 -> 命名 -> 移动到文件夹 -> 手写相对路径代码）。

  • 这个插件只需要剪贴板一键粘贴： 可使用截图工具截好图（图片存在剪贴板中），在 VS Code 中按下粘贴快捷键 Command + V即可，还可以直接进行拖拽。

  • 插件会自动将剪贴板的图片保存到当前目录下，并以时间戳命名，同时在你的光标处自动生成 Markdown 的图片引用语法，例如![](image/2023-10-24-10-00-00.png)。
    (4) Code Spell Checker

  • 主要用于避免低级英文拼写错误。

🥳以上就是vscode中写md文件时的一些好用的插件，用起来非常的丝滑～🥳

👇下面是在部署到博客的时候，由于上述图片使用的是本地位置，无法共享到网页，因此我们需要搭建一个图床，这里主要是用的是PicGo插件，5分钟设置成功之后，就也可以实现快捷键直接插入图片并上传了！超级惊喜！
