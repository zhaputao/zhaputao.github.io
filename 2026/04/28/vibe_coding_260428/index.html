vibe coding 入门介绍

发表于2026-04-28|更新于2026-08-22|人工智能
|总字数:1.9k|阅读时长:5分钟|浏览量:

偶然看到了Vibe coding，感觉很有意思，做一个非常简单的入门介绍，希望能够了解它的同时，自己也进行一些实践。

什么是Vibe coding?

Vibe意思是氛围、感觉，Vibe coding指的是由AI驱动的全新软件开发。它于2024年底到2025年在硅谷和技术圈火爆起来，简单来说，vibe coding指的是程序员不再纠结于具体的语法、逻辑实现或调试细节，而是通过与 AI进行自然语言对话，通过描述“想要的功能”和“感觉（Vibe）”来构建软件。

OpenAI联合创始人Andrej Karpathy发表的推文将这个概念介绍的更加彻底，他曾提到Vibe coding对其的感受，一些小的项目可以完全依赖LLMs，如果遇到一个LLMs不能解决的问题，他会选择绕过这个问题，或者做一些随机的修改只要错误不再出现就行。

📌所以说为什么叫Vibe? 一方面是因为我们通常只要出来的结果感觉对了，代码跑通了我们的目的就达到了；另一方面，我们通常给AI的提示都是“你这里写的不对，我想要的是圆润的风格，你现在的风格太强硬了”等这种偏个人情绪的prompt。（💡这个想法感觉很有意思）

Vibe coding和AI-assisted coding的区别

我们平常借助AI进行编程的方式，叫做AI辅助编程（AI-assisted coding），这与上面说Vibe coding借助AI进行软件设计等，并不完全一样。
区别主要如下表所示，其实就是AI-assisted主要辅助我们进行局部的改动，大的框架主要是自己来写的；而vibe coding则主要是我们只告诉自己的想要的东西，整体的代码框架和细节都是AI自己完成，（主打一个一行代码也不写，代码写完如果自己功底差的话如果想看懂也会比较费劲hhh）。

维度 AI-Assisted Coding Vibe Coding
主要工具 GitHub Copilot, Tabnine Cursor,Windsurf, Replit Agent
交互粒度 代码行、函数级 功能模块、整站级
人类角色 自己写代码，AI 帮忙补全(主笔人) 描述需求，AI 负责编写和集成(导演)
关注点 语法正确、算法逻辑、代码规范 用户体验、功能实现、整体意图
门槛要求 需要编程功底和调试能力 极低，更看重产品思维和“提示词”能力

vibe coding似乎对于代码功底很差的人，如果有一个bug一直修改不出来，可能会没有办法继续写下去，可能项目就不了了之了。我就是那个代码功底很差的人，所以1️⃣代码生成完都尽量尝试看懂一下，结合自己做的项目比自己临时找的其他项目代码可能更容易看懂2️⃣是其实可以多尝试几个不同的AI，或者新开一个对话框，感觉有的时候是对话有点疲劳了，就降智了。

常用的 vibe coding 工具

下面的这些除了Cursor和Trae我都不知道，但是主流的我将一一尝试，并写出教程。

Cursor

Cursor是一个全能型 AI 编辑器（适合：开发者和深度定制项目）
这类工具通常是基于 VS Code 开发的，能够理解我们整个项目的上下文，直接在本地修改代码。

  • 特点： 目前 Vibe Coding 的标杆。它的 Composer 模式允许用一句话修改几十个文件，并且它能预测我们下一步操作，并自动补全。
  • 用途： 现有的复杂项目维护、重构、或者从零开始构建一个商业级软件。

Windsurf

  • 特点： 强调 Flow。它引入了 Cascade 功能，AI 能够像人类一样在一个持续的任务流中思考，甚至可以自己运行终端命令来测试它写的代码是否正确。
  • 用途： 需要高度自动化的多步骤任务，比如“帮我把所有接口增加鉴权逻辑并更新所有单元测试”。

Trae

  • 特点： 2025 年崛起的强力竞争者，主打自适应 AI，对中文语境理解极佳，且目前在性能和响应速度上对标 Cursor，甚至在某些特定场景下更流畅。
  • 用途： 追求极致响应速度，适合中文支持的开发者。

下面的这属于浏览器原生构建工具，比较适合：快速原型和非技术人员，因为这类工具不需要配置任何本地环境，直接在网页里聊天就能看到网站上线。

Lovable / Bolt.new

  • 特点： 真正的 Vibe 驱动。只要给它一张设计图，或者描述一下“我想要一个复古电影风格的博客”，它会瞬间生成精美的前端界面、配置好后端数据库，并直接给我们一个可以访问的网址。
  • 用途： 快速制作 MVP（最小可行性产品）、着陆页、个人作品集。

Replit Agent

  • 特点： 一站式全栈代理。它不仅写代码，还会帮你买域名、配置服务器、设置数据库。你只需要像指挥员工一样告诉它：“帮我做一个类似闲鱼的二手交易小程序。”
  • 用途： 独立开发者快速上线完整的 Web 应用。

下面的属于UI/UX 专项工具，适合前端美感要求高的人。

v0

  • 特点： 专注于 UI 组件。基于 React、Tailwind CSS 和 Shadcn UI。它生成的界面极其符合现代审美，且代码极其规范。
  • 用途： 快速生成一个漂亮的网页组件（比如仪表盘、精美的注册框），然后直接复制到你的项目里。

下面的属于Agent 终端工具，适合硬核自动化的人

laude Code / GitHub Copilot CLI

  • 特点： 命令行里的“氛围大师”。不需要图形界面，在终端输入 claude build a weather app，它会自己在那蹦跶几分钟，把整个文件夹建好，依赖装好，程序跑起来。
  • 用途： 脚本编写、系统维护、快速搭建基础架构。

展望

虽然vibe coding会变的越来越普遍，但是并不意味着软件工程师的价值会被剥削，相反我觉得，因为vibe coding 写出来的东西如果想要正在用于生产线上，还是需要有经验的工程师进行审查，而且，如果在平时的coding中一直卡在一个问题上，更会说明这个问题被大家遇到的不够多，这就更需要有价值的工程师了。因此，我觉得与其恐惧，不如掌控，进而提升。
