🔗 BFS

BFS（Breadth-First Search，广度优先搜索），是图搜索算法中非常经典的方法。在机器人路径规划中，它们经常用于 二维栅格地图上的全局路径规划。

简而言之：BFS的思想就是我一层一层往外扩散，第一次找到目标就是最短路。

图示遍历过程

  1. 首先，需要明确的是BFS是以 队列（deque） 为核心，其搜索核心是从始结点开始。如下图所示，选取V1为初始节点，下方的“顶点访问顺序”就是队列。

    先选取了V1所以V1进入队列。
  2. 接下来寻找，与V1外面的一层，也就是与V1相连的节点，分别是V2和V3。

    选中V2和V3，将其写入队列中。
  3. V1外围的节点寻找完毕，队列弹出V1。
  4. 找队列中最开始的节点，现在是V2，因此寻找V2的外围节点，分别是V4和V5。

    将V4和V5写入队列，并弹出V2。
  5. 找队列中最开始的节点，现在是V3，因此寻找V3的外围节点，分别是V6和V7。

    将V6和V7写入队列，并弹出V3。
  6. 循环下去，找V4的外围节点V8,加入队列，弹出V4；找V5的外围节点V8已被访问过，故不做处理，弹出V5；
    找V6的外围节点V7已被访问过，故不做处理，弹出V6；
    依次弹出V7、V8。
  7. 此时，队列为空，遍历结束。

    从可视化的过程中，是遍历的过程，我们还没说明为什么能做到最短路径。

最短路径的确定

要用 BFS 得到最短路径，还需要在第一次发现某个节点时，额外记录：这个节点是由哪个节点搜索到的。

通常用一个 parent （父节点/前驱节点）字典保存。

对于图中每条边长度都相同的情况(无权图)，可以把一条边的代价看成 1。

BFS 按照距离起点的层数搜索：

在上述的图中，以V1为起点：

在搜索第 层之前，BFS 一定已经搜索完第 层的所有节点。
所以 BFS 第一次发现 V8 时，一定已经使用了最少的边数。

感觉这里可以理解为所有的路径都是可以写成层树的结构。

因此，它不可能先找到一条长度为3的路径，之后才发现长度为2的路径，所以说，从V1到V8只需要走3步。

看到这里，我们也能理解为什么BFS会被广泛用于求无权图的最短路径问题了。

🔗 Dijkstra 算法

Dijkstra算法和BFS算法两者关系非常紧密。可以把它们理解为：BFS 是 Dijkstra 在“所有边权都相同”情况下的特殊形式。

Dijkstra 博士仅仅是在陪未婚妻喝咖啡的时候，花了20分钟想出来的算法，成为了非常著名的算法之一。

Dijkstra 算法是机器人路径规划中最经典的图搜索算法之一，主要用于解决：带非负边权图中，从起点到目标点的最短路径问题。
Dijkstra算法采用：
表示：当前已知从起点 到节点 的最短距离估计。

Dijkstra算法的核心思想是：“广度优先搜索”结合“贪心策略”。
